# 🌐 Ankit Parida - Portfolio

A modern, interactive portfolio website built with the MERN stack featuring a cyberpunk/hacker aesthetic with dark/light mode support.

## 🌍 Live Demo

- **Frontend:** [https://port-folio-dusky-one.vercel.app](https://port-folio-dusky-one.vercel.app)
- **Backend API:** [https://portfolio-eevk.onrender.com](https://portfolio-eevk.onrender.com)

---

## ✨ Features

### 🎨 Design & UX
- **Cyberpunk/Hacker Theme** - Neon green aesthetic with matrix background
- **Dark/Light Mode** - Seamless theme switching with persistence
- **Fully Responsive** - Optimized for all devices (mobile, tablet, desktop)
- **Interactive Animations** - Typing effects, glitch text, fade-in animations

### 📄 Pages & Sections
- **Home** - Profile with typing animation, GitHub projects feed, social links
- **About** - Education, summary, soft skills, contact information
- **Skills** - Technical skills, GitHub & LeetCode links
- **Projects** - Featured projects with GitHub, Vercel, and Render links
- **Contact** - Contact form with email notifications and MongoDB storage

### ⚙️ Technical Features
- **Contact Form** - Saves messages to MongoDB with instant email notifications
- **GitHub Integration** - Displays repositories with stars, forks, and language stats
- **Resume Download** - One-click PDF resume download
